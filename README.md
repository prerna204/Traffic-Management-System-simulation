# 🚦 Traffic Management System Simulation 🚗

A simulation developed from scratch using **Pygame** to simulate the movement of vehicles across a traffic intersection with traffic lights and timers.

## 📝 Description

This project is a simulation of an intelligent Traffic Management System that dynamically allocates green signal time based on the real-time vehicle density in each lane. Unlike traditional systems that assign fixed signal timings, this simulation prioritizes lanes with higher vehicle density, optimizing traffic flow and reducing congestion. The system continuously monitors vehicle count and adjusts signal timings to ensure efficient and smooth movement across intersections.

## ✅ Prerequisites

- **Python 3.1+** 🐍

## 💻 Installation

### Step I: Clone the Repository

```bash
git clone https://github.com/prerna204/Traffic-Management-System-simulation
```

### Step II: Install the Required Packages

On the terminal, move into the **Basic-Traffic-Intersection-Simulation** directory:

```bash
pip install pygame
```

### Step III: Run the Code

To run the simulation:

```bash
python simulation.py
```

## ✨ Features

- **🚦 Real-Time Traffic Simulation:** Vehicles move through intersections based on signal states.
- **⏲️ Dynamic Signal Timing:** Green Signal Time (GST) is adjusted based on lane congestion.
- **🚑 Emergency Vehicle Detection:** Emergency vehicles like ambulances are prioritized with automatic green signals.
- **🚘 Vehicle Classification:** Vehicles are categorized into emergency and non-emergency for optimized flow.
